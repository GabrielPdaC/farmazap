Política de Privacidade — FarmaZap

Extensão para o navegador Google Chrome · Última atualização: 3 de novembro de 2026

1. O que é o FarmaZap

O FarmaZap é uma extensão para farmácias municipais que usam o sistema G-MUS. Ao finalizar uma baixa/saída de medicamentos, ela mostra ao atendente os medicamentos entregues com suas datas de término e, se o atendente quiser, envia essas datas ao paciente pelo WhatsApp Web.

2. Quais dados a extensão acessa

Somente no momento em que o atendente finaliza uma baixa/saída, a extensão lê no G-MUS:

  • nome e código do paciente;
  • telefone do cadastro do paciente;
  • medicamentos entregues, duração e data de término de cada um.

A leitura usa a sessão do G-MUS já aberta pelo atendente. A extensão não pede, não lê e não armazena senhas, e não altera, cria nem exclui nenhum registro no G-MUS.

3. Como os dados são usados

  • Para exibir ao atendente uma janela com o paciente, o telefone e os medicamentos.
  • Para montar a mensagem com os medicamentos que o atendente escolher.
  • Para enviar essa mensagem pelo WhatsApp Web, somente quando o atendente confirma o envio.

Os dados não são usados para nenhuma outra finalidade, como publicidade, perfis ou análise de crédito.

4. Onde os dados ficam

Tudo acontece no navegador do computador da farmácia. O FarmaZap não tem servidor, e nenhum dado é enviado ao desenvolvedor ou a terceiros, com uma exceção: a mensagem que o atendente decide enviar ao paciente pelo WhatsApp (item 5).

Telefone do paciente, lista de medicamentos e texto das mensagens não são armazenados.

5. Compartilhamento

A mensagem confirmada pelo atendente é enviada ao paciente pelo WhatsApp, operado pela Meta, como qualquer mensagem enviada manualmente pelo WhatsApp Web. Esse envio segue a política de privacidade do WhatsApp. Nenhum outro compartilhamento é feito, e os dados não são vendidos.

6. Permissões da extensão

  • storage: guardar as configurações e o histórico descritos no item 4.
  • Acesso a saoleopoldo.g-mus.com.br: detectar a finalização da baixa/saída e ler os dados do item 2.
  • Acesso a web.whatsapp.com: abrir a conversa e enviar a mensagem confirmada pelo atendente.

7. Responsabilidade e direitos do titular (LGPD)

Os dados dos pacientes pertencem ao cadastro da farmácia no G-MUS. O FarmaZap é apenas uma ferramenta usada pela farmácia no atendimento. Pedidos de acesso, correção ou exclusão de dados, conforme a Lei Geral de Proteção de Dados (Lei nº 13.709/2018), devem ser feitos à farmácia ou à Secretaria Municipal de Saúde responsável pelo cadastro.

Para apagar todos os dados guardados pela extensão, basta removê-la do navegador.

8. Contato

Dúvidas sobre esta política: abra uma solicitação em github.com/GabrielPdaC/farmazap/issues.

9. Alterações

Esta política pode ser atualizada quando a extensão mudar. A data da última atualização fica no topo da página.

O FarmaZap é uma ferramenta independente, sem vínculo com o WhatsApp/Meta nem com a Inovadora (G-MUS).
